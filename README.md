# Enduro (sport4you.co.il) — חבילת פתיחה לבנייה

הקובץ הזה נועד להיקרא ע"י Claude Code בתחילת הסשן הראשון של הבנייה בפועל.
כל האפיון, ההחלטות, וההכנה בוצעו מראש בצ'אט נפרד. זה הסיכום המעשי.

## מסמך האפיון המלא
כל הרקע העסקי, הארכיטקטורה, ה-SEO, תהליך ההגירה, מפרטי הסוכנים, יעדי הצמיחה,
והגאנט השנתי נמצאים במסמך המלא כאן:
https://claude.ai/code/artifact/016323b6-7a07-4978-bb84-7d75dccd2c7f

**קרא את המסמך הזה לפני שמתחילים לכתוב קוד.**

## מה יש בתיקייה הזו

- `source/wordpress_export.xml` — קובץ הייצוא המלא מוורדפרס (WXR). מכיל את כל 70
  עמודי/פוסטי התוכן עם הטקסט המלא (title, content:encoded), כותרות H1-H4,
  ומטא-דאטה של Yoast SEO (focus keyword, meta description) איפה שקיים.
- `source/images/` — 105 התמונות שנבחרו לשימור (מתוך 196 ייחודיות שנסקרו,
  אחרי הסרת 91 שסומנו למחיקה ע"י תומר). שמות הקבצים בפורמט `NNN_שם-מקורי.jpg`
  כאשר NNN הוא המספר מרשימת הסקירה המקורית (לצורך מעקב בלבד).
- `decisions/enduro-full-page-list.csv` — **מקור האמת** לכל 62 עמודי התוכן:
  איזה עמוד נשמר, נמחק, או ממוזג (ולאן). עמודה `decision` מכילה את ההחלטה הסופית.
- `decisions/enduro-content-audit.csv` — ביקורת SEO מלאה לכל עמוד: כמות H1,
  כמות H2, ספירת מילים, focus keyword ו-meta description מ-Yoast (איפה שקיים).
- `decisions/enduro-media-keep-list.csv` — רשימת 105 התמונות שנשמרו, עם הנתיב
  המקורי שלהן בשרת (`wp-content/uploads/YYYY/MM/...`).

## החלטות מפתח שכבר סגורות (אל תשאל עליהן שוב)

- **סטאק טכני:** אתר סטטי (Astro/Next.js Static Export), בלי וורדפרס, בלי בסיס
  נתונים. אחסון מוצע: Netlify או Vercel.
- **חנות אונליין (WooCommerce):** יורדת לגמרי מהאתר החדש.
- **מערכת חברים/Login (Ultimate Member):** יורדת לגמרי - אין שימוש פעיל.
- **עמודי "כפילות עירונית"** (מאמן כושר אישי/לילדים לפי עיר): נשארים כעמודים
  נפרדים (כי מגיעה תנועה ישירה לכל עיר), אבל כל אחד נכתב מחדש עם תוכן ייחודי
  אמיתי לאותה עיר - לא טמפלט מועתק עם שם עיר מוחלף.
- **עמוד "לוח תחרויות ריצה"** הוא עמוד התנועה החזק ביותר באתר (88 קליקים מתוך
  271 ב-28 יום) - עדיפות עליונה לשימור מדויק + הפיכתו לעמוד עם סוכן אוטומציה.
- **301 Redirects חובה** לכל עמוד שנמחק/מוזג - יש למפות כל כתובת ישנה לחדשה
  לפני העלאה לאוויר, כדי לא לאבד דירוג SEO קיים.
- **קוד ה-DMR האישי** (`tomera_27dmr`, פירוט בסעיף 6 במסמך) הוא **חסוי** - לא
  לפרסום בעמוד הטבות ציבורי.
- **Analytics:** אין גישה לחשבון GA/GTM הקיים (שייך למפתח הקודם). יש להקים
  חשבון GA4 חדש תחת חשבון Google האישי של תומר.

## נקודת התחלה מוצעת לסשן הראשון

1. קרא את מסמך האפיון המלא (קישור למעלה).
2. עבור על `decisions/enduro-full-page-list.csv` וודא הבנה של כל שורה.
3. התחל בבניית רכיבי הליבה (כותרת, פוטר, תבנית עמוד) לפי סעיף 3 במסמך.
4. השתמש בתוכן מתוך `wordpress_export.xml` (לא מהאתר החי) כמקור לטקסט.
5. השתמש בתמונות מתוך `source/images/` (לא מהזיפ המקורי - זה כבר הסט הסופי).
